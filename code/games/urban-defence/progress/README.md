# Urban Defence progress board

Open `progress/board.html` (in a browser, from a local server in the `urban-defence` folder, e.g. `python3 -m http.server 8000`, then http://localhost:8000/progress/board.html).

- The checklist, screenshots, performance charts, element table, physics bulletin and news log are all here.
- The "seed 7 / seed 3 / seed 11 / Live game" links open the game (`../pixel-world.html`) so you can play the seeds from the board.
- The bulletin posts are kept in the browser's local storage when there is no board server. On the live board server they are saved to `bulletin.json`.
